## Key Concepts Explained

Throughout the docs, you'll encounter these core concepts:

### Environment
An isolated workspace with:
- Git branch for version control
- Docker container for execution
- Worktree for filesystem isolation

**Learn more:** [Environment Workflow](/environment-workflow), [Architecture](/architecture)

### MCP (Model Context Protocol)
Standard protocol for AI agents to interact with tools.

**Learn more:** [MCP API Reference](/mcp-api-reference), [Agent Integration](/agent-integrations)

### Worktree
Git feature providing filesystem isolation without checking out in main repo.

**Learn more:** [Architecture](/architecture)

### Container State
Snapshot of container filesystem and configuration, stored in Git notes.

**Learn more:** [Architecture](/architecture)

### Configuration
Project settings for base image, dependencies, and setup commands.

**Learn more:** [Environment Configuration](/environment-configuration)

### Secrets
Sensitive data (API keys, passwords) referenced but not stored.

**Learn more:** [Secrets Management](/secrets)

### Search
Use the search bar (top right) to find specific topics across all documentation.

### Examples
Most documentation includes code examples. Look for:
- 💡 Code blocks with syntax highlighting
- 📝 Example commands and outputs
- ⚠️ Common mistakes to avoid

### Navigation
- **Sidebar** - Browse all pages
- **Table of Contents** - Jump to sections within page
- **Breadcrumbs** - See where you are in hierarchy
